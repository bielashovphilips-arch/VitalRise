# Точний раціон і продовження виконання — 07.10.2026

Оновлення виконує запит довести «Харчування» до 9/10 за його головною метою: отримати практичний раціон під ціль і дотримуватися конкретних порцій. Оцінка 9/10 є продуктовим орієнтиром, а не медичною сертифікацією.

## Що змінено

- 79 із 113 продуктів мають спільний USDA SR Legacy запис для калорій, БЖВ, клітковини, насичених жирів і натрію. Калорії готового курячого філе виправлено з 110 на 165 ккал/100 г; сухого білого рису — з 350 на 365. Стара група білих риб уточнена до атлантичної тріски; йогурт і тофу теж мають конкретний вид. Попередній звіт від 06.10 описує стан до цих виправлень.
- Автоматичні межі сирих/сухих порцій масштабуються за парою довідкових станів. Для готових продуктів уточнено спосіб приготування. Власні продукти й непевні суміші не отримують вигаданих показників.
- Генератор після початкового складання виконує обмежений детермінований пошук практичних порцій та гарнірів. Враховує калорії/БЖВ, щонайменше 400 г овочів/фруктів, 25 г клітковини, до 10% енергії із насичених жирів та натрій. Невеликий запас клітковини й натрію допомагає уникати відхилень через округлення; додані соуси й сіль все одно треба враховувати.
- Прибрано приховані продукти при порожньому виборі категорії. Усі автоматичні позиції відповідають вибору, дієті, меті й дозволеним прийомам. Зміни ручного меню та заміни не запускають оптимізацію інших порцій.
- Активне меню, точні ручні грами, застосовані заміни та режим зважування відновлюються після перезавантаження в тому самому браузері. Скидання очищає активне меню. Збереження меню не означає виконання прийомів.
- Закритий блок поживної якості показує, чи всі три показники в межах орієнтирів, є відхилення або бракує даних. Уточнено загальний ліміт солі: менше 5 г/день для дорослих, включно з їжею, а не дозу для досолювання. Прибрано автоматичне підвищення солі за вагою/спекою.

## Перевірка та межі

Автоматизована матриця: 64 сценарії для чоловіка 80 кг/178 см і жінки 58 кг/164 см, 28 років, активність 1,55; чотири цілі, 3–6 прийомів, готове/сире зважування. Усі пройшли допуски ±5% калорій, ±8% БЖВ, критерії овочів/фруктів і трьох показників поживної якості. Це перевірені приклади, а не гарантія для всіх можливих параметрів або обмежених наборів продуктів.

Playwright охоплює підтвердження однієї заміни, відновлення готового й ручного меню, точні десяткові грами, скидання, позначки виконання, шаблони, рецепти, експорт, три мови й ширини 1440/390/320. Зміни не вводять окремий щоденник «Сьогодні».

Фінальні локальні перевірки: `npm run check` успішний; об’єднані тести харчування, аналізів, тренувань і регресій сайту — 39 успішних, 0 нових збоїв, 1 раніше відомий TODO для відсутнього старого фото `nutrition-athlete.jpg`. Оновлено версії ресурсів і кешів service worker для всіх дев’яти сторінок.
