# VitalRise — матеріали для погодження

Дата: 7 вересня 2026. Цей пакет не опублікований. Дизайн сайту не змінювався під час створення відео.

## Перегляд

Відкрити `index.html` у браузері. Або запустити `npm run preview:growth` із кореня проєкту та перейти на http://127.0.0.1:4174/deliverables/vitalrise-launch/.

- `vitalrise-demo-30s.mp4` — повне демо: калькулятор, демонстраційний результат, Start, адреса сайту.
- `vitalrise-teaser-15s.mp4` — коротка версія: вступ, результат, заклик спробувати.
- Обидва відео: вертикальні 1080×1920, 30 кадрів/с, MP4/H.264; українські написи, без озвучення й музики.
- `cover.png`, `demo-frame-280.png`, `story-result.png`, `story-start.png` — обкладинка та кадри для Stories.
- `promotion-content-uk.md` — підписи до роликів, три Stories, три додаткові дописи, два рекламні тексти, тижневий план і UTM-посилання.
- `video-script-uk.md` — сценарій та окремий текст для можливого озвучення.
- `vitalrise-first-week-DRAFT.pdf` і `pdf-bonus-preview.png` — запропонований односторінковий чекліст. Не персональний план; на сайт не доданий.
- `verification.json` — результат перевірки фінальних відео та незмінності захищених файлів дизайну.

## Перед публікацією

1. Погодити матеріали й перевірити відповідність показаних текстів та ціни живому сайту: відео використовує локальну версію з погодженими текстовими виправленнями.
2. Підтвердити право рекламного використання наявного фото атлета. Особисті фото власника для цього демо не потрібні.
3. Додати реальне посилання у профіль/стікер Stories: намальована у відео кнопка не є інтерактивною.

Жодних рекламних кампаній, розсилок, оплат або публікацій цей пакет не запускає. Підготовка матеріалів не означає, що весь план SEO, аналітики й email-просування завершено.

## Відтворення експорту для розробника

Джерела Remotion — `video/vitalrise-demo/`. З кореня проєкту:

```powershell
node tools/capture-promo.mjs
npm --prefix video/vitalrise-demo run render:demo
node tools/render-short-promo.mjs
node tools/finalize-promo.mjs
node tools/verify-promo.mjs
```

За потреби вказати встановлений Chromium через `--browser-executable` для повного рендера. Короткий рендер також приймає шлях із `PLAYWRIGHT_CHROMIUM_EXECUTABLE`. Фіналізація видаляє службову тиху аудіодоріжку й нормалізує відеоформат; перевірка декодує всі кадри, тестує відтворення й перемотування в браузері, експортує PNG та звіряє 11 контрольних сум дизайну. Тестовий сервер не надсилає заявки й платежі.
